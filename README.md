# 🚨 Telegram-бот обліку повітряних тривог

Простий та автономний бот для відстеження повітряних тривог у Дніпропетровській області та розрахунку точного часу простою бізнесу під час робочого дня.

Бот автоматично зчитує сповіщення з офіційного каналу (`t.me/s/sirena_dp`), розрізняє **🔴 Червоний** та **🟡 Жовтий** рівні загрози й рахує втрачені робочі години.

---

## 📌 Що вміє бот

* **📊 Звіт за сьогодні** — підраховує, скільки годин магазин фактично працював, а скільки був зачинений через тривоги у робочий час (10:00 — 19:00).
* **📅 Статистика за 7 днів** — показує підсумки простою за тиждень із деталізацією по кожному дню та рівнях загрози.
* **🔴/🟡 Поточний статус** — миттєво відповідає, чи є тривога просто зараз і скільки часу вона вже триває.
* **⏰ Автоматичний щоденний звіт** — щодня о 19:05 надсилає підсумкову статистику дня в робочий чат Telegram.

---

## 🛠️ Як це влаштовано

Проект написаний на **Python** (`pyTelegramBotAPI`, `BeautifulSoup4`, `schedule`, `Flask`).

Бот повністю **stateless** — він не потребує бази даних і збирає актуальну картину безпосередньо з джерела при кожному запиті. Вбудований Flask-сервер дозволяє хостити його безкоштовно 24/7 на **Render** у зв'язці з **UptimeRobot** (для захисту від засинання).

---

## ☁️ Деплой на Render (Free Tier)

1. Створіть новий **Web Service** на [Render.com](https://render.com) та підключіть цей репозиторій.
2. Вкажіть налаштування:
   * **Build Command:** `pip install -r requirements.txt`
   * **Start Command:** `python alarm_tracker.py`
3. У розділі **Environment Variables** додайте ваші секрети:
   * `BOT_TOKEN` — токен від `@BotFather`
   * `CHAT_ID` — ID чату для щоденних звітів
4. Налаштуйте безкоштовний монітор у [UptimeRobot](https://uptimerobot.com) на URL вашого Render-сервісу з інтервалом в 5–10 хвилин, щоб бот не вимикався через неактивність.
